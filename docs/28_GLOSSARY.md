# Project Glossary

## NWP
Numerical Weather Prediction — physics-based weather model forecast output.

## Post-processing
Statistical/ML correction or calibration applied after an NWP forecast is produced.

## MOS
Model Output Statistics — statistical post-processing relating model output to observations.

## Weather regime
A recurring atmospheric/circulation state used to condition forecast errors/corrections.

## Active monsoon
A broad monsoon state associated with enhanced monsoon activity; use exact operational definition only when documented.

## Break monsoon
A broad monsoon state with suppressed monsoon rainfall over large parts of the core monsoon region; exact labeling method must be documented.

## Monsoon low/depression
Synoptic low-pressure system associated with organized monsoon rainfall.

## Orographic rainfall
Rainfall enhanced through terrain-forced ascent.

## Raw NWP
Uncorrected genuine forecast output from a documented NWP model/cycle.

## Observation / reference
Dataset used as verification truth/reference. Its source must be named.

## Reanalysis
Retrospective atmospheric reconstruction that assimilates observations. Not identical to a real-time forecast.

## Lead time
Time from forecast initialization to forecast valid time.

## Accumulation period
Time interval over which precipitation is summed, e.g. 6h or 24h.

## Calibration
Statistical property/processing linking forecast probabilities/distributions to observed frequencies.

## Reliability
For probability forecasts, whether events predicted with probability p occur about p fraction of the time.

## RMSE
Root Mean Square Error.

## POD
Probability of Detection.

## FAR
False Alarm Ratio.

## CSI
Critical Success Index.

## ETS
Equitable Threat Score.

## FSS
Fractions Skill Score — spatial neighbourhood verification metric.

## Brier Score
Mean squared error of binary event probabilities.

## Mixture-of-Experts
Architecture combining specialist model outputs through a gating mechanism.

## Hard routing
Choose one expert, usually by maximum regime probability.

## Soft routing
Weight multiple experts by regime/gating probabilities.

## Leakage
Use of information during training/inference that would not actually be available for the forecast being made.

## Historical replay
Retrospective inference for a past case where observation is now known.

## Operational forecast
Inference produced using information available at forecast issue time, before the event is observed.
