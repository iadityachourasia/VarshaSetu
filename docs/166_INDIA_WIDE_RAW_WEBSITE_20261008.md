# India-wide Raw rainfall map in the local website — 8 October 2026

The website now has a first-class `/india` page, a primary navigation link and an overview-page entry point. It displays **historical, unmodified NOAA GEFS control rainfall** for included 2023–2025 cases on the full 129×135, 0.25° IMD grid (6.5–38.5°N, 66.5–100°E). The page offers a research-boundary land display and the complete forecast grid including sea. It shows the frozen Raw-only regional verification for the chosen year and links the same case to the established regional Raw → corrected → IMD view. It does **not** fill India with an untested M2 correction.

## Data path and meaning

- `GET /api/science/evidence/all-india-raw/cases?year=` lists only the frozen ledger's `INCLUDED` cases and reports which arrays are locally available. `GET .../grid?year=&case_id=` accepts only such a case, checks the complete `.npy` SHA-256 against the frozen ledger **before decoding**, validates 129×135 finite nonnegative rain, and returns source, case, 24-hour window, grid and hash metadata. Missing arrays return unavailable; changed bytes are an integrity failure. No observation is read by these endpoints.
- The land display is clipped to the exact pinned 2021 simplified geoBoundaries ADM2 geometry (735 local features, SHA-256 `d68db39cd3e2d0892af268e2b0454166368ce3b5b8a78fcda63069ec92a641db`). This is a **visual research mask**, not the IMD reference mask, an official district boundary or a verification population. The full-grid option shows every forecast cell, including sea. The frozen Raw verification remains based on its own IMD valid-cell intersection; its counts must not be inferred from the map mask.
- The existing ignored, hash-receipted all-India Raw cache supplies all available included cases locally. A small write-once fallback bundle contains the three 2025-09-26 Raw leads only, copied byte-for-byte after checking their frozen ledger hashes. Its manifest SHA-256 is `e3e810d6416494a54854ce4d65a677996633948495b0ff34c49a7eb11ea53dd9`; `scripts/build_india_map_demo_bundle.py --check` verifies it without decoding values. The bundle contains no IMD values, trained models or corrected fields. If the large cache is absent, the page still has these three research-demo cases rather than inventing a map.
- The existing regional correction remains 10–22°N, 68–80°E. The east-coast 2024 development candidate failed Raw on aggregate RMSE, heavy CSI and FSS (`docs/162`); it is not displayed or promoted. North, north-east and southern corrected skill remain unknown. The 2025 all-India Raw verification is a consumed-test post-hoc analysis, not a new independent test.

An initial overview browser run had one stale layout expectation after the new entry was inserted; the entry was moved into a separate context strip and the rerun passed. Frontend typecheck, lint, **212/212** unit tests and production build passed; the build generated 19 routes. The global `*.npy` ignore rule now has a narrow exception for only the three small demo arrays so the bundle is portable in the uncommitted checkout.

Final read-only checks exited 0: demo bundle `--check`, integrated four-workstream audit, and `git diff --check` (Windows line-ending notices only). The 2026 scorer preflight still returned `BLOCKED_BEFORE_OBSERVATION_READ` for 213 leads. C: had 189,752,963,072 bytes free (about 176.7 GiB). No commit, 2026 observation access, new training job or corrected-model promotion occurred.

This makes the **website's geographic forecast-input view India-wide**, not the scientifically validated corrected product. Public deployment still needs a source/geometry-rights review and a portable storage plan for more than the three bundled demo cases. India-wide corrected output requires stage-trained forecast-only models, same-case Raw/global comparisons, event support, a genuinely independent comparable year and authorized geometry before a region is connected.
