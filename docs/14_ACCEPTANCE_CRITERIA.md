# Phase 1 Gate — SIH mandatory

## PS-R01 Raw NWP
- [ ] Genuine forecast source documented.
- [ ] Init time present.
- [ ] Valid time present.
- [ ] Lead present.

## PS-R02 AI/ML post-processing
- [ ] At least one trained correction model.
- [ ] Held-out evaluation exists.

## PS-R03 Regime classifier
- [ ] Reproducible labels/method.
- [ ] Forecast-time predictors.
- [ ] Independent validation.

## PS-R04 Regime-conditioned correction
- [ ] Regime state actually changes correction path/weights.

## PS-R05 Improvement vs raw
- [ ] Raw and corrected evaluated against same observations.
- [ ] At least one relevant skill improvement demonstrated or limitations honestly reported.

## PS-R06 Grid output
- [ ] Corrected rainfall exists on a 2-D grid.

## PS-R07 Heavy probability
- [ ] Event accumulation and threshold correctly defined.
- [ ] Probability generated by real model.
- [ ] Calibration evaluated or clearly labeled prototype.

## PS-R08 District product
- [ ] Official/traceable district geometry.
- [ ] Grid-to-district aggregation.
- [ ] Table/map rendered.

## PS-R09–R14 Metrics
- [ ] RMSE.
- [ ] ETS.
- [ ] CSI.
- [ ] POD.
- [ ] FAR.
- [ ] FSS.

# Phase 2 Gate — Scientific credibility

- [ ] Feature registry contains forecast-time availability.
- [ ] No leakage found by semantic audit.
- [ ] Strong non-regime baseline present.
- [ ] Rare-event counts disclosed.
- [ ] Calibration reliability evaluated.
- [ ] Lead-time breakdown reported.
- [ ] Failure cases retained.
- [ ] Experiment metadata reproducible.

---

# Phase 3 Gate — USP

Soft MoE:
- [ ] hard-routing baseline retained,
- [ ] soft expert blending implemented,
- [ ] same train/test data for comparison,
- [ ] gains/losses reported honestly,
- [ ] regime probability calibration assessed.

Physics:
- [ ] features based on documented equations,
- [ ] units validated,
- [ ] ablation shows effect or feature is not advertised as beneficial.

# UI Gate

- [ ] No fake scientific values.
- [ ] Every displayed scientific value has backend source.
- [ ] Historical vs operational modes clearly labeled.
- [ ] Threshold accumulation visible.
- [ ] Source/model/lead visible.
- [ ] Raw/corrected/observed comparison uses consistent units.
- [ ] Judge can find mandatory metrics quickly.

---

# Demo Gate

Before any official demo:
- [ ] select at least one held-out case,
- [ ] run replay from stored artifacts,
- [ ] show aggregate held-out report,
- [ ] show event counts,
- [ ] show known limitations,
- [ ] offline fallback for demo artifacts prepared,
- [ ] no external dependency that can silently break the entire demonstration.
